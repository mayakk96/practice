Fictional educational network timeout runbook. A timeout means the caller did not receive a usable response within its budget; it does not prove the downstream payment network did not process the authorization. Retries use the same transaction ID as the downstream idempotency reference. Retry only bounded transient network failures, HTTP 429 and eligible 5xx responses. Honor bounded Retry-After delays. Request errors, authentication failures and conflicts are not blindly retried. Inspect request correlation IDs, dependency latency, retry counters, network health and the downstream reference. A malformed response is a dependency contract failure rather than a valid approval. Preserve the instruction for investigation when the final outcome remains ambiguous. This local mock can inject timeouts, rate limits and server errors; these are synthetic incidents. The model assistant may suggest checks but cannot submit or authorize a payment.
